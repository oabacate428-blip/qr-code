# objetivo
Esta ferramenta gratuita transforma QR codes comuns em peças visuais personalizadas e profissionais.

Principais recursos:

Customização Visual: Ajuste de tamanho, arredondamento das bordas dos módulos e dos cantos ("olhos"), além de aplicação de cores e gradientes.

Identidade de Marca: Inserção de logotipos ou fotos centralizadas sem prejudicar a leitura.

Molduras e Textos: Adição de chamadas para ação (CTAs) emolduradas.

Exportação Flexível: Download em alta resolução (PNG, JPG) ou formatos vetoriais (SVG, EPS) ideais para web e impressões de qualquer escala.

Tudo de forma prática, rápida e 100% gratuita.

## Stack de Tecnologia
Backend: PHP estrutura com sessões ativas e javascript .
Banco de dados: SQL com PDO para a segurança. Frontend: HTMM, CSS usando bootstrap.
