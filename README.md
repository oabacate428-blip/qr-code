# qr-code
Crie QR codes gratuitos e personalizados com esta ferramenta completa! Ajuste o tamanho, escolha o arredondamento das bordas, adicione cores, gradientes e insira o logo da sua marca ou fotos no centro. Exporte em alta resolução ou vetor (SVG/PNG) para impressões perfeitas. Prático, rápido e 100% gratuito para uso pessoal ou profissional!
